# ✈️ EastChat — Кроссплатформенный Мессенджер

**EastChat** — это современный, быстрый и безопасный мессенджер, который работает прямо в браузере и на Android. Проект вырос из простого HTML-файла в полноценную экосистему с чатами, звонками, эфирами и внутренней экономикой.

## 💎 Что умеет EastChat?

Мы не делали очередную «пустышку». В проекте реализован сложный функционал, который обычно требует команды разработчиков:

*   💬 **Чаты и Каналы:** Личные переписки, публичные каналы (с галочкой верификации) и групповые чаты.
*   ⚡ **Real-time синхронизация:** Сообщения доставляются за миллисекунды благодаря Firebase Firestore.
*   📞 **Голосовые звонки:** Полноценные P2P-звонки (1 на 1) на базе WebRTC и PeerJS. *(Для звонка нужно ввести UID друга, который можно скопировать в профиле)*.
*   📺 **Прямые эфиры:** Видеотрансляции внутри групп и каналов через интеграцию с Jitsi Meet.
*   🎥 **Кружки (Видеосообщения):** Запись видео прямо с камеры и отправка в чат (хранилище на Supabase Storage).
*   💼 **Бизнес-режим:** Панель управления для бизнеса. Включает в себя профессиональные автоответы для клиентов (когда вы заняты) и специальный бейдж 💼 в профиле.
*   🪙 **EastCoins:** Внутренняя валюта для отправки анимированных подарков в чатах.
*   👑 **EastChat Premium:** Подписка (симуляция оплаты) с золотой короной в профиле.
*   🔐 **Безопасность:** Строгие правила Firestore (Security Rules) защищают переписку от посторонних глаз.

## 🛠 Технологический стек

Проект написан на чистом JavaScript без использования тяжелых фреймворков (React/Vue). Вся магия — в правильной архитектуре.

*   **Frontend:** HTML5, CSS3 (переменные, Flexbox/Grid), Vanilla JavaScript (ES6+).
*   **База данных и Авторизация:** Firebase (Auth, Firestore).
*   **Хранилище медиа:** Supabase Storage.
*   **Звонки и P2P:** PeerJS (WebRTC).
*   **Эфиры:** Jitsi Meet API.
*   **Хостинг:** Netlify (веб-версия), GitHub Releases (APK).

## 🧪 Как тестировать фичи?

1. **Звонки:** Зарегистрируй два аккаунта (например, на ПК и на телефоне). Нажми на свой аватар в левом верхнем углу и скопируй свой **UID**. В личном чате нажми кнопку **📞** и введи UID друга — начнется звонок!
2. **Эфиры:** Создай **Группу** (кнопка `+`), зайди в неё и нажми **📺**. Отправь ссылку на группу другу, чтобы он подключился к трансляции.
3. **Бизнес-режим:** Зайди в меню профиля (нажми на аватар) -> выбери **«💼 Бизнес-аккаунт»** -> нажми «Активировать». Теперь, если кто-то напишет тебе в личку, бот автоматически ответит профессиональным сообщением.
4. **Кружки:** Включи камеру и запиши видео до 60 секунд, оно автоматически загрузится в Supabase и появится в чате.
